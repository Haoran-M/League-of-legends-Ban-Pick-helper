`chaincc/PROVENANCE.json` records the CC BY 4.0 professional-play preparation
audit. The large `patch-*.json` aggregate exports are generated by
`scripts/prepare_history.py` and excluded from Git; they remain reproducible
using the pinned input described in DATA_SOURCES.md. The runnable app uses the matching packaged
`src/league_draft/resources/seed.sqlite3` copied into writable user storage.

`demo/` is a schema-compliant CSV example with explicitly synthetic counts.
The JSON equivalent is `src/league_draft/resources/demo.json`.
See SCHEMA.md and the root DATA_SOURCES.md for the contract and attribution.
